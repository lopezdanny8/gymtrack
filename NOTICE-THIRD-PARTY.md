# Aviso de código reutilizado

GymTrack Web reutiliza y adapta componentes de una base de software existente para entrenamiento. Los archivos de licencia, avisos de copyright y obligaciones de distribución aplicables se conservan en el repositorio.

La identidad de producto, la interfaz web y las nuevas funcionalidades se desarrollan bajo el nombre GymTrack. Este aviso existe para mantener una atribución clara y no forma parte de la marca visible de la aplicación.

Antes de distribuir modificaciones fuera de este repositorio, revisar `LICENSE` y los avisos incluidos por cada dependencia o componente reutilizado.
